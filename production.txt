## 1. Deployment Configuration Audit

### 1. `INTERNAL_API_KEY` (`PASS`)

### 2. Email Delivery (`PASS`)
- **Provider Policy**: In `NODE_ENV=production`, `EMAIL_PROVIDER="mock"` is strictly rejected at startup.
- **Supported Providers**: `"sendgrid"` (mandating `SENDGRID_API_KEY`) or `"smtp"` (mandating `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`).
- **Reliability & Deduplication**: Features exponential backoff retry (up to 3 attempts) and in-flight mutex locks preventing duplicate emails.
- **Failure Isolation**: Email delivery transient failures are safely recorded in `TournamentEmailDelivery` and do not crash or block tournament match progression or wallet transactions.

### 3. Redis / Multi-Node Socket.IO (`PASS`)
- **Protocol Validation**: `REDIS_URL` enforces `redis://` or `rediss://` URL schemes with credentials sanitization.
- **Pub/Sub Synchronization**: Automatically binds `@socket.io/redis-adapter` when `REDIS_URL` is set, syncing events, room states, and broadcasts across multiple server instances.
- **Single-Server Support**: Transparently falls back to in-memory adapter when running a single server without Redis.
- **Fault Tolerance**: Automatic reconnection with exponential backoff on Redis disconnection events.

### 4. CORS Policy (`PASS`)

- **Strict HTTPS**: Enforces explicit frontend domains (e.g. `https://gaminghub.com` or `https://app.gaminghub.com`).

## 3. Remaining Deployment Blockers & Configuration Required

There are **zero code blockers**. To deploy to production hosting (e.g. AWS ECS, GCP Cloud Run, Kubernetes, Render, Railway), provide the following environment variables in the hosting platform's secret manager:

### Required Environment Variables for API:
```bash
NODE_ENV=production
PORT=4000
DATABASE_URL="postgresql://<DB_USER>:<DB_PASS>@<DB_HOST>:<DB_PORT>/<DB_NAME>?sslmode=require"
JWT_SECRET="<SECURE_RANDOM_JWT_SECRET_32_BYTES>"
INTERNAL_API_KEY="<SECURE_RANDOM_INTERNAL_KEY_32_BYTES>"
CORS_ORIGIN="https://yourdomain.com"
SOCKET_SERVER_INTERNAL_URL="http://socket-server:4001"
EMAIL_PROVIDER="sendgrid" # or "smtp"
SENDGRID_API_KEY="SG.<YOUR_SENDGRID_KEY>"
EMAIL_FROM="noreply@yourdomain.com"
DB_CONNECTION_LIMIT=20
```

### Required Environment Variables for Socket Server:
```bash
NODE_ENV=production
PORT=4001
API_URL="http://api:4000"
JWT_SECRET="<MATCHING_JWT_SECRET>"
INTERNAL_API_KEY="<MATCHING_INTERNAL_KEY>"
CORS_ORIGIN="https://yourdomain.com"
REDIS_URL="rediss://:<REDIS_PASS>@<REDIS_HOST>:<REDIS_PORT>" # Required if running >= 2 socket replicas
```

### Required Environment Variables for Web Frontend:
```bash
VITE_API_URL="https://api.yourdomain.com"
VITE_SOCKET_URL="https://socket.yourdomain.com"
```
